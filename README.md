Training Portal
====================

> [!NOTE]
> **Archived, last changed in December 2016.** This 2016 web app asked users questions about their database to improve entity recognition. It is kept for history and is not run anywhere.
>
> **Today's replacement:** the training Playground inside [package-named-entity-linker](https://github.com/TalkingDB/package-named-entity-linker) (`playground/`), where entities, surface texts and test cases are trained and checked. Synonyms can be harvested from Wikipedia with [ConceptDigger](https://github.com/TalkingDB/ConceptDigger).

Takes input of user's database, and asks user questions about their database. Answering the questions inside Training Portal will improve the accuracy of CommandNet Processor.
